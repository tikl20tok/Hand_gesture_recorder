# Hand_Gesture_Recorder
**(description in code is Vietnamese)**
Using python and OpenCV and Media Pipe Hands.
Very high speed (sustain 18-27ms on Intel Core Duo T6500)
Running flow:
👌: Start record.
👍: End record.

Requirements:
Normal chip
At least 200mb of free RAM (though it just about 50-100mb)

Notices:
This programm is fully optimized, DOES NOT FILL RAM because it write into disk when triggered and buffer it into mp4 when it end

Videos:
Currently: 720p 16:9 and 30fps
**You can change the file extension and also resolutioin and fps.
Video will be saved in "foldervideo" in this file (i don't want to use "videofolder" because i'm afraid of ressemblance though it is follow grammar standard) (You can change up to you)

Bonus function:
Auto delete old file (>16 days). YOU ALSO CAN CHANGE THIS IN MAIN CODE!

I highly recommend export it into exe after you made you customize change.

In the futrue, I will make better GUI for simplification, QR and Bar code.
